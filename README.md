# ChromaDB plugin for aaPanel

*[Español más abajo](#español)*

Installs and manages a [ChromaDB](https://www.trychroma.com/) vector database server from the aaPanel UI.

## Features
- **One-click install / upgrade / uninstall** of any stable ChromaDB release ≥ 1.0.0 (picked from PyPI).
- **Hardened service**: systemd unit running as the unprivileged `chroma` user, bound to `127.0.0.1` only,
  read-only filesystem except its data directory, no capabilities, private `/tmp`, memory limit.
- **Optional remote access** through an nginx proxy: token required on every request
  (`Authorization: Bearer <token>` or `X-Chroma-Token: <token>`), IP allow-list, per-IP rate limit,
  SSL using one of your sites' certificates, and automatic aaPanel firewall rules.
- **Collections & databases**: list, create, delete.
- **Backups**: create (consistent, brief stop), restore (validated, previous data kept), download, delete,
  schedulable from panel Cron.
- **Logs** (journald) and copy-paste **connection snippets** (Python, Node.js, curl).
- English / Spanish UI.

## Requirements
| | |
|---|---|
| aaPanel | 7.x (tested on the Python 3.12 panel runtime) |
| OS | Linux with systemd (tested: Ubuntu 22.04) |
| Arch | x86_64 or aarch64 |
| nginx | installed by aaPanel; ≥ 1.25.1 for the SSL option |
| Disk / RAM | ~400 MB disk for the runtime; ≥ 1 GB free RAM recommended |
| Network | access to pypi.org and GitHub (python-build-standalone) during install |

## Install the plugin
1. Download `chromadb-<version>.zip` from [Releases](https://github.com/jalexiscv/chromadb-plugin-for-aapanel/releases/latest).
2. aaPanel → **App Store** → **Third-party** → **Import plugin** → upload the zip.
3. Open the plugin → **Status** → choose a version → **Install ChromaDB**.

## Paths
| Path | Content |
|---|---|
| `/www/server/panel/plugin/chromadb/` | plugin code |
| `/www/server/chromadb/` | runtime (isolated Python, venv), `config.yaml`, `settings.json` |
| `/www/server/chromadb/data/` | ChromaDB data |
| `/etc/systemd/system/chromadb.service` | service unit (generated) |
| `/www/server/panel/vhost/nginx/chromadb_remote.conf` | remote proxy (only when enabled) |
| `/www/backup/chromadb/` | backups |

`config.yaml`, the systemd unit and the nginx file are generated by the plugin — change settings in the UI.

## Scheduled backups
Panel → **Cron** → type *Shell script*:
```bash
/www/server/panel/pyenv/bin/python /www/server/panel/plugin/chromadb/chromadb_main.py backup
```

## Security notes
- ChromaDB 1.x (Rust server) has **no built-in authentication**. Protection relies on binding to localhost and,
  for remote access, on the token proxy. When enabling remote access, use SSL and an IP allow-list.
- The remote token is stored in `/www/server/chromadb/settings.json` and the nginx file, both `root:root 0600`.

## Uninstall
- From the plugin: *Uninstall (keep data)* or *Uninstall and delete data*.
- Removing the plugin from the App Store removes the runtime and keeps `/www/server/chromadb/data`.

## Build
```bash
bash build.sh        # → dist/chromadb-<version>.zip + .sha256
```

## Español

Instala y administra un servidor de base de datos vectorial [ChromaDB](https://www.trychroma.com/) desde aaPanel.

**Funciones:** instalación/actualización/desinstalación en un clic (versiones estables ≥ 1.0.0 desde PyPI);
servicio systemd endurecido con usuario `chroma`, solo en `127.0.0.1`; acceso remoto opcional mediante proxy nginx
con token, lista blanca de IPs, límite de peticiones, SSL y reglas automáticas en el firewall del panel;
colecciones y bases de datos; respaldos (crear, restaurar, descargar, programar con Cron); logs; ejemplos de conexión;
interfaz en español e inglés.

**Instalación del plugin:** descarga el zip desde [Releases](https://github.com/jalexiscv/chromadb-plugin-for-aapanel/releases/latest); luego aaPanel → **App Store** → **Third-party** → **Import plugin** → sube el zip.
Luego abre el plugin → **Estado** → elige la versión → **Instalar ChromaDB**.

**Requisitos:** aaPanel 7.x, Linux con systemd, x86_64 o aarch64, nginx ≥ 1.25.1 para SSL,
~400 MB de disco, acceso a pypi.org durante la instalación.

**Respaldos programados:** Panel → **Cron** → tipo *Shell script*:
`/www/server/panel/pyenv/bin/python /www/server/panel/plugin/chromadb/chromadb_main.py backup`

**Seguridad:** ChromaDB 1.x no tiene autenticación propia; la protección depende de escuchar solo en localhost y,
para acceso remoto, del proxy con token. Si activas el acceso remoto, usa SSL y lista blanca de IPs.
